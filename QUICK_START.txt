⚡ 5-MINUTE SETUP
═══════════════════════════════════════════════════════════════════

1. PREREQUISITES
   ✓ XAMPP installed with PHP 8.1+ and MySQL
   ✓ Composer installed
   ✓ Git Bash or PowerShell (Windows)

2. OPEN TERMINAL
   Windows CMD:      cd c:\xampp\htdocs\didx-laravel
   PowerShell:       cd c:\xampp\htdocs\didx-laravel
   Git Bash:         cd /c/xampp/htdocs/didx-laravel
   Linux/Mac:        cd ~/xampp/htdocs/didx-laravel

3. RUN SETUP SCRIPT
   
   Windows (Batch):
   > setup.bat
   
   OR
   
   PowerShell:
   PS> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   PS> .\setup.ps1
   
   OR Manual:
   > composer install
   > php artisan key:generate
   > php artisan migrate

4. START SERVER
   > php artisan serve

5. OPEN BROWSER
   http://localhost:8000/dashboard

✅ DONE! Application is running locally.

🛠️  ESSENTIAL COMMANDS
═══════════════════════════════════════════════════════════════════

Server Management:
   Start Server      → php artisan serve

   Stop              → Press Ctrl+C

Database:
   Run Migrations    → php artisan migrate
   Reset Database    → php artisan migrate:reset
   Refresh Database  → php artisan migrate:refresh

Cache/Debug:
   Clear Cache       → php artisan cache:clear
   Clear Views       → php artisan view:clear
   View All Routes   → php artisan route:list
   Interactive Shell → php artisan tinker

⚠️  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Problem: Connection refused (Database)
→ Solution: Edit .env and set DB_HOST=localhost

Problem: Port 8000 in use
→ Solution: php artisan serve --port=8001

Problem: "Class not found" error
→ Solution: composer dump-autoload

Problem: Route not found (404)
→ Solution: php artisan route:clear

Problem: Views won't render
→ Solution: php artisan view:clear
